# Title: Funds Donation Website
#### Video Demo:  https://youtu.be/ydsqzGDePGk
#### Description:
**Layouts/layouts.html**: My first step was creating a navbar for my project. I was initially going to use the Bootstrap navbar but I decided to make a custom responsive navbar. For this purpose, I took help from a YouTube video about navbars and decided to make one accordingly. I learned a lot from the video regarding SVGs, responsiveness, etc. I then made further adjustments myself.
I inserted the flashed message code here, making some changes based on the finance problem set flash message code. I asked ChatGPT if that code would be viable and made changes accordingly.

**Homepage/index.html**: Secondly, from Bootstrap I took a carousel and made changes to it, changing certain colors of the buttons and texts to better suit my goals. I then inserted images inside it. I also included descriptions for my website, about its launching and what our goals are. I included a credibility page as well. One more thing I looked up on YouTube was a custom footer—I didn’t want to use Bootstrap’s footer, so I thought a better approach would be to learn more from YouTube and design my footer accordingly. These are the two things I used YouTube to guide me on.

**Donate/donate.html**: For my donation page, I really wanted to incorporate the JS that Professor Malan taught, the live search suggestion. At first, I was going to use Bootstrap’s custom search feature which is quite simple. But I decided to use a search PNG image where users can click and search accordingly. I set up all that with some help from ChatGPT.
I then decided to use cards for showing the organizations where there would be an image, a description, and a donate button for each of the funds/organizations. Users could select a fund and donate the amount they wished for. I successfully implemented the live search suggestion. It was such a pain to implement; I was getting stuck many times but eventually, with the help of ChatGPT, I overcame the problem.
I also created a modal that would pop up whenever a user clicked on the donate button where they had to enter their email, password, confirm their password, their credit card number, and amount they wanted to donate. I used JS to apply Luhn's algorithm. I again asked GPT how I could include Luhn’s algorithm on my website. I created some CSS styling for the live search suggestions, and then I used JS to make the suggestions clickable. I tried a demo code but there were some problems coming up so I asked ChatGPT what the issue was, took its suggestions, and improved my code. So whenever a user clicked an organization name, the card would pop up and they would be able to donate.
Setting up the POST request was also quite a challenge but nonetheless, I succeeded. I also made it so that 5 of the organizations would always be visible upon visiting the donate page for better user experience.

**Sign Up/register.html**: I created a signup page for users to sign up where they could enter their email and password accordingly. I designed a beautiful signup page using Bootstrap features and some new fonts for the labels. I ensured proper margin and padding. Initially, I was struggling with the responsiveness part but I got stuck so I decided to ask ChatGPT for help. I again learned more about responsiveness from that and created a responsive signup page accordingly. For my background, I was about to use normal background coloring but I learned about linear gradients and applied it to my page accordingly.

**Log In/login.html**: The login is the same as signup but there is just no confirm password input. I made the design accordingly so that users can hop between their login and signup pages. I also decided to include a forgot password mechanism below the password input box. I made the background the same for consistent user experience and applied the same CSS styling for responsiveness and beautification.

**Email verification/reset.html**: In this HTML page, I prompted the user for their email for password recovery and if the email matched the email within the database records, I redirected them to forgot.html where users could change their passwords. I used the same layout here too for consistent user experience.

**Password Change/forgot.html**: In this page, I used two input boxes: one for entering their new password and another for confirming their new entered password. After submitting this page, the users would have their passwords updated in the database. I used the same layout here too for consistent user experience.

**History/history.html**: For creating a history page, I used the data stored in the donations table to display an HTML table. I searched for attractive table designs on YouTube using HTML/CSS and watched a video to learn about table designs. I took some inspiration and implemented some CSS to design my history table and made it look as attractive and user-friendly as I possibly could.

**Apology/apology.html**: This page is just for rendering apologies to the user upon running into some errors during backend checks. I used the same concept as the one from the finance problem set to render apologies to users. I learned that using this would be more efficient as it prevents redundancy in code.

**app.py**: Here I have implemented all the necessary backend verifications for security and smooth user experience. I have used password hashing from werkzeug.security to store user info when they login. I also have set sessions upon successful login. From ChatGPT, I found out that I could use the email_validator module to validate emails and use attributes associated with it to format emails in a proper way. I have cleared the session upon user wanting to log out. I use Luhn's algorithm in the backend as well to verify credit card information and I have used a @login_required route to only allow logged-in users to donate. I used the same login custom decorator as in the finance problem set and I understood the code in detail.
I have used the flash features to notify users upon successful registration, login, password change, logout, donations, and for partial email verification feature too. I used the apology feature from the finance problem set to display proper apology messages. I have used jsonify to create an API for returning a JSON response to the HTML template for my live search suggestions. I was getting stuck there too but I learned that API calls should always be separate routes while JSONifying. I also created the /donate backend to always return 5 cards no matter what upon clicking on the donate button. I stored the funds data in my funds table and the donation info of individual users in the donations table.
For my history page, I only render the history page if users are logged in; otherwise, I prompt users to log in first, flashing them a message. After users log into their account, they are presented with an attractive history table with donation info containing the fund name, donation amount, and the date on which they donated. I used ChatGPT's help on converting the date to a more user-friendly format.

**SQLite3**: I used SQLite3 to create a fund.db database consisting of three tables: one where users’ signup data is stored, one where the funds data is stored, and one where donations data is stored. I first decided on the columns myself that I should add on the tables then I asked ChatGPT if those columns would suffice. I then took ChatGPT’s feedback to improve my table layout.

**menu.txt / close.txt / requirements.txt**: These are the SVGs I used for my navbar to make it more user-friendly. The last file contains the packages I downloaded to make this project a success.
